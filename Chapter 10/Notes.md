## 📌 Introduction to Data Structures

In programming, a **Data Structure** is a specialized format for organizing, storing, managing, and manipulating data efficiently. 

To store and manage multiple values under a single reference, we utilize these structures rather than declaring individual variables for every single value.

---

## 🛠️ Classification of Data Structures in Python

Python's data structures are broadly categorized into two types:

### 1️⃣ Built-in Data Structures
These are standard data structures provided out-of-the-box by Python. They are highly optimized and ready to use. In Python, there are four primary built-in data structures:
* **List**
* **Tuple**
* **Dictionary**
* **Set**

*(Note: We will explore each of these built-in types in detail in the subsequent sections of this chapter.)*

### 2️⃣ Custom Data Structures
These are user-defined data structures that developers build manually (typically using classes and objects) to solve complex algorithmic problems. Examples include:
* **Stack**
* **Queue**
* **Linked List**
* **Graph**, etc.

---

## 🧮 Data Structures and Algorithms (DSA)

Along with data structures, we study various **Algorithms** to process and manipulate the stored data effectively. These include:
* **Searching Algorithms** (e.g., Linear Search, Binary Search)
* **Sorting Algorithms** (e.g., Bubble Sort, Merge Sort, Quick Sort)

The combined study of how we organize data (structures) and the step-by-step procedures we design to interact with or manipulate that data (algorithms) is known as **Data Structures and Algorithms (DSA)**.
